# Комментарий автору FurnaceService

Формулы сохранены без изменений по решению заказчика. Просьба проверить следующие места по исходной методике:

1. В `HeatBalanceFull._calculate_final`, C52 = 100 − rd − C_direct_Fe − gas_consumption − limestone_rate. Здесь rd — доля, C_direct_Fe — кг/т, газ — м³/т, известняк — кг/т. На значениях формы rd=0.35, coke_rate=420, gas_consumption=115, limestone_rate=0 результат C52 отрицательный. Подтвердите назначение C52, единицы слагаемых и знак коэффициентов C56/C60/C65/C69/C73/C77/C81.
2. При rd=0, gas_consumption=0, blast_humidity=0 или slag_rate=0 заключительные коэффициенты делят на ноль. Это должны быть запрещённые режимы либо нужны формулы предельных случаев? До уточнения API будет явно отклонять режимы, для которых существующие формулы не определены.
3. pellets_rate присутствует во входе, но не используется в формулах. Так и задумано, или его нужно учитывать вместе с ore_rate?
4. C59 использует C45 (доля остаточного тепла), а не теплоту разложения известняка. Просьба подтвердить ссылку на ячейку.

Для окончательной проверки нужны эталонный набор входов и ожидаемые промежуточные/итоговые Cxx с единицами измерения. Техническая сборка и тесты транспорта не подтверждают физическую корректность формул.
